## 3. Struktur repository
Repository dibagi menjadi `frontend/` (PHP, HTML, Tailwind CSS), `backend/` (Flask API dan model Decision Tree), `database/` (skema SQLite), `docs/` (SRS, diagram UML, panduan), `scripts/`, dan `.github/` (template issue dan pull request). Penjelasan lengkap ada pada `README.md`.

## 4. Alur kerja yang dipakai
- Branch `main` untuk kode stabil, `develop` untuk integrasi, dan `feature/*` atau `fix/*` untuk pekerjaan individu.
- Pekerjaan dicatat sebagai **issue** dan dikaitkan ke kebutuhan SRS (FR/NFR).
- Setiap perubahan masuk melalui **pull request** yang direview minimal satu anggota lain.
- Pesan commit mengikuti format `jenis: ringkasan` (feat, fix, docs, chore, dan seterusnya).
Rincian ada pada `CONTRIBUTING.md` dan `docs/PANDUAN_GIT.md`.
